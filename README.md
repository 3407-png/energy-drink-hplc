# 제로 에너지 드링크 HPLC 동시분석 — 표준물 첨가법 정량 도구

카페인 · 소듐벤조에이트 2종을 HPLC-UV로 동시분석하고,
표준물 첨가법의 x절편 역산으로 매트릭스 간섭이 보정된 실제 농도와
변환 상수를 계산한다.

## 계산 내용

### 표준물 첨가법 역산

첨가 농도 x, 피크 면적 A에 대해 `A = k·x + A₀` 를 적합하고,

```
x절편 = −A₀ / k        →   |x절편| = 바이알 내 원래 농도
음료 원액 농도 = |x절편| × 희석배수(10)
1캔당 mg = 음료 원액 농도(mg/L) × 제공량(L)
```

x절편의 표준오차는 외삽 오차식으로 계산한다.

```
s(x₀) = (s_y/x ÷ |k|) · √( 1/n + ȳ² / (k²·Σ(xᵢ−x̄)²) )
```

표준물 첨가법은 데이터 구간 **바깥**을 외삽하는 방법이라, 기울기와 R²만
보고하고 이 불확도를 빼면 신뢰도를 평가할 수 없다. 보고서 표에는 95%
신뢰구간까지 같이 나온다.

### 변환 상수

```
f = (첨가법으로 역산한 참 농도) / (외부 검량선으로 읽은 겉보기 농도)
```

- `f > 1` : 매트릭스가 응답을 억제 → 외부 검량선법이 과소평가
- `f < 1` : 공용리 등으로 면적이 부풀어 → 외부 검량선법이 과대평가

`f ≈ 1 / (k/m)` (k = 첨가법 기울기, m = 검량선 기울기) 관계가 성립하므로,
변환 상수의 실체는 대부분 **곱셈형 매트릭스 효과의 역수**다. 보고서에서
이 둘을 나란히 보여 주므로 그대로 서술 근거로 쓸 수 있다.

## 연구 계획에서 하나 짚어야 할 점

계획서의 **가설 둘째**는 이렇게 적혀 있다.

> 모든 바이알에 시료 원액 농도를 동일하게 고정하면 방해 물질의 간섭이
> 수학적으로 Y절편의 상승에만 국한된다. 농도를 결정하는 기울기는 첨가된
> 표준물질에 의해서만 결정되므로 (…) 화학적 간섭의 한계를 극복할 것이다.

이 서술은 반만 맞다. 매트릭스 간섭에는 두 종류가 있다.

**① 곱셈형 (multiplicative)** — 매트릭스가 단위 농도당 응답을 바꾼다.
기울기가 변한다. 표준물 첨가법이 **보정해 준다.** 표준물질도 같은
매트릭스 안에서 같은 비율로 영향을 받기 때문이다. 첨가법을 쓰는 이유가
바로 이것이다.

**② 덧셈형 (additive, 공용리)** — 리보플라빈처럼 타깃과 같은 시간대에
겹쳐 나오는 성분이 면적을 그대로 더한다. y절편만 올라간다.
표준물 첨가법은 이걸 **보정하지 못한다.** 오히려 A₀가 부풀어 x절편이
그만큼 과대평가된다. `A₀`의 10%가 리보플라빈 몫이었다면 역산 농도도
10% 과대평가다.

계획서가 근거로 든 "y절편 상승에만 국한된다"는 상황은 정확히 ②에
해당하고, ②는 첨가법으로 해결되지 않는다. 실제로 첨가법이 해결해 주는 건
①이다. 이건 방법론이 틀렸다는 뜻이 아니라 **근거 서술을 바꾸면 되는
문제**이고, 오히려 논의거리가 하나 늘어난다.

- 보고서 7절(덧셈형 간섭 민감도)에서 ②의 크기를 정량해 준다.
- 대응은 수학이 아니라 크로마토그래피다: 분리능 Rs ≥ 1.5 확보,
  PDA로 피크 순도(스펙트럼 일치) 확인, 두 파장에서의 면적비 비교.
- 리보플라빈은 230 nm에서도 흡광하고 역상에서 카페인과 비슷한 시간대에
  나올 수 있으므로, 표준액 카페인 피크와 시료 카페인 피크의 UV 스펙트럼이
  같은지 반드시 확인할 것.

가설 문장은 이렇게 고치면 사실에 맞는다.

> 매트릭스에 의한 **응답계수 변화(기울기 변화)**는 표준물 첨가법으로
> 보정된다. 다만 공용리에 의한 **면적 가산**은 첨가법으로 보정되지 않으므로,
> 크로마토그래피 분리와 피크 순도 확인으로 별도 통제한다.
